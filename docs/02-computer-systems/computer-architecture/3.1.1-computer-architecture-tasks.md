## Task One: components

For each item, describe its purpose. Include the full name of each abbreviation.

1. Input device
2. Output device
3. Central processing unit (CPU)
4. Control unit (CU)
5. Arithmetic and logic unit (ALU)
6. Registers
7. Random access memory (RAM)
8. Read-only memory (ROM)
9. Secondary storage
10. Cache

Give three examples of input devices and three examples of output devices.
