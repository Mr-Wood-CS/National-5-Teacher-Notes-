# Parallel 1D Arrays

!!! info "What you need to know"

    You must be able to describe, exemplify and implement **parallel 1D
    arrays**.

## Related Data in Separate Arrays

A 1D array stores a collection of related values. In a set of **parallel
arrays**, the value at one index is related to the values at the same index in
the other arrays.

```python
pupil_names = ["Peter", "Laura", "Marie"]
pupil_marks = [20, 21, 23]
```

The arrays are parallel because:

- `pupil_names[0]` and `pupil_marks[0]` both describe Peter
- `pupil_names[1]` and `pupil_marks[1]` both describe Laura
- `pupil_names[2]` and `pupil_marks[2]` both describe Marie

The index connects the related values.

| Index | `pupil_names` | `pupil_marks` |
|---:|---|---:|
| 0 | Peter | 20 |
| 1 | Laura | 21 |
| 2 | Marie | 23 |

## Accessing Corresponding Values

Use the same index with every parallel array:

```python linenums="1"
pupil_names = ["Peter", "Laura", "Marie"]
pupil_marks = [20, 21, 23]

index = 2
print(pupil_names[index], "scored", pupil_marks[index])
```

This displays Marie's name and mark. Using different indexes would combine
values belonging to different pupils.

## Traversing Parallel Arrays

A loop can process every pupil while keeping the arrays aligned:

```python linenums="1"
pupil_names = ["Peter", "Laura", "Marie"]
pupil_marks = [20, 21, 23]

for index in range(len(pupil_names)):
    print(pupil_names[index], "scored", pupil_marks[index])
```

The arrays should contain the same number of elements. The program uses the
length of one array because matching elements occupy matching positions.

## Adding Related Data

When adding a new item, update every parallel array:

```python linenums="1"
pupil_names = []
pupil_marks = []

name = input("Enter pupil name: ")
mark = int(input("Enter pupil mark: "))

pupil_names.append(name)
pupil_marks.append(mark)
```

Both values are added at the same index, so their relationship is preserved.

## Updating Corresponding Values

Use the same index when changing a value in one of the arrays:

```python linenums="1"
pupil_names = ["Peter", "Laura", "Marie"]
pupil_marks = [20, 21, 23]

pupil_marks[1] = 24
print(pupil_names[1], "scored", pupil_marks[1])
```

Index `1` represents Laura in both arrays, so the program changes Laura's mark
and displays `Laura scored 24`.

## Strengths and Risks

Parallel arrays are straightforward when a problem already uses 1D arrays, but
their indexes must remain synchronised. Adding, removing or sorting a value in
one array without making the same change to the others breaks the relationship.

Records provide another way to group related values. They are introduced in
the next lesson.
