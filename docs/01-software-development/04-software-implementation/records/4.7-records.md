# Records

!!! info "What you need to know"

    You must be able to describe, exemplify and implement records.

A **record** groups related fields that may have different data types. A pupil
record could contain a string name, an integer age and a Boolean permission.

## Defining a Record

Python can represent a record with a dataclass:

```python linenums="1"
from dataclasses import dataclass

@dataclass
class Pupil:
    name: str = ""
    age: int = 0
    permission: bool = False
```

`Pupil` is the record structure. `name`, `age` and `permission` are its fields.
Each field has an identifier, a data type and a default value.

## Creating and Updating a Record

```python linenums="1"
pupil = Pupil()
pupil.name = "Aisha"
pupil.age = 16
pupil.permission = True
```

`pupil` is one record created from the `Pupil` structure. Dot notation selects
a field, such as `pupil.name`.

Values can also be supplied when the record is created:

```python
pupil = Pupil("Aisha", 16, True)
```

## Reading Fields

```python linenums="1"
print("Name:", pupil.name)
print("Age:", pupil.age)
print("Permission:", pupil.permission)
```

Records keep all the data about one item together. This is clearer than using
separate, unrelated variables such as `pupil_name`, `pupil_age` and
`pupil_permission`.
