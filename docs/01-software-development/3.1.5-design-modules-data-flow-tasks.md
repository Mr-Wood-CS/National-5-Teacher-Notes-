# Design Tasks: Modules and Data Flow

Use each scenario to practise a different Higher design technique.

Each task tells you whether to present your answer as a:

- **structure diagram**
- **pseudocode design**
- **data flow table**

Remember:

- `IN` means data passed into a module
- `OUT` means data passed out of a module
- files, keyboards, screens and users are not data flow
- data flow should show the variables or arrays passed between modules

| Task | Required design technique |
|---|---|
| Task 1: Countries | Structure diagram |
| Task 2: Test Marks | Data flow table |
| Task 3: Aircraft Capacity | Pseudocode design |
| Task 4: Ticket Booking | Structure diagram |

## Task 1: Countries

Write a program that reads in a list of one hundred countries from a text file.

It asks the user to enter a capital letter and uses input validation to make sure only one character is entered.

Then it runs through every country in the list and checks if it starts with that letter. If so, it should add 1 to a counter.

At the end of the program, it displays the number of countries starting with that letter.

**Required technique:** Structure diagram

Create a structure diagram for this program. Show the modules and the data flow between them.

Use the module and data flow details below to help build your diagram.

| Module | IN | OUT |
|---|---|---|
| Read countries from text file |  | `Countries` |
| Get capital letter from user |  | `Letter` |
| Is only 1 character entered? | `Letter` | `Valid` |
| Find country that meets criteria | `Countries`, `Letter` | `Counter` |
| Display number of countries that meet criteria | `Counter` |  |

## Task 2: Test Marks

A teacher has a text file containing each pupil's name, and for each pupil, three test marks out of 20.

The program should read this data from a text file. The second module should use the data to calculate three grades, A, B and C, for each pupil: one for each test.

The next module should count how many pupils got three As, and the final module should display how many this was.

**Required technique:** Data flow table

Complete a data flow table for this program. Show the data that flows into and out of each module.

## Task 3: Aircraft Capacity

An airline uses a program to decide the most efficient aircraft to assign to a particular route.

There is a text file containing a list of aircraft types, their range, and passenger capacity.

The program needs to ask the user to input the number of passengers on a route, and the distance between airports.

The program should then loop through the aircraft types and find the smallest aircraft that can hold that many passengers while having enough range. It should then display the name of this aircraft type.

**Required technique:** Pseudocode design

Write the top-level pseudocode design for this program. Show the data flow on the right-hand side of each main step.

Use the module and data flow details below to help build your pseudocode.

| Module | IN | OUT |
|---|---|---|
| Read aircraft name, capacity and range from text file |  | `Names`, `Capacities`, `Ranges` |
| Get passenger number and range needed from user |  | `PassengerNum`, `RangeRequired` |
| Find smallest aircraft that meets these criteria | `Names`, `Capacities`, `Ranges`, `PassengerNum`, `RangeRequired` | `SelectedName` |
| Display name of selected aircraft | `SelectedName` |  |

## Task 4: Ticket Booking

A ticket booking system allows users to go online to buy concert tickets.

It has a text file containing a list of current bookings. It gets user input for how many tickets they want to buy.

It checks how many tickets have already been booked in the file and calculates if there are still tickets available.

If there are tickets available, it passes the ticket cost to another module.

The program displays the cost. It then adds the new booking to the file.

**Required technique:** Structure diagram

Create a structure diagram for this program. Show the modules and the data flow between them.

Use the module and data flow details below to help build your diagram.

| Module | IN | OUT |
|---|---|---|
| Read text file with current bookings data |  | `Bookings` |
| Get number of required tickets from user |  | `TicketsWanted` |
| Are new tickets still available? | `Bookings`, `TicketsWanted` | `Available`, `NewBooking` |
| Display total cost | `TicketCost` | `TotalCost` |
| Write new booking into text file | `NewBooking` |  |
