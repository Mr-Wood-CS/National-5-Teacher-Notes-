# Arrays of Records

!!! info "What you need to know"

    You must be able to describe, exemplify and implement arrays of records.

An **array of records** stores several records with the same structure. Each
element represents one complete item.

## Creating an Array of Records

```python linenums="1"
from dataclasses import dataclass

@dataclass
class Pupil:
    name: str = ""
    age: int = 0
    registration_class: str = ""

pupils = [Pupil() for index in range(3)]
```

`pupils` contains three empty `Pupil` records. A field is selected using an
array index followed by dot notation, such as `pupils[0].name`.

## Entering Data

```python linenums="1"
for index in range(len(pupils)):
    pupils[index].name = input("Enter name: ")
    pupils[index].age = int(input("Enter age: "))
    pupils[index].registration_class = input("Enter registration class: ")
```

The same index is used for all fields belonging to one pupil.

## Traversing the Array

```python linenums="1"
for index in range(len(pupils)):
    print(pupils[index].name, pupils[index].age,
          pupils[index].registration_class)
```

The loop visits every record in order. Unlike parallel arrays, each pupil's
related values stay together inside one element.

## Searching Records

```python linenums="1"
target_name = input("Enter a pupil name: ")
position = -1

for index in range(len(pupils)):
    if pupils[index].name == target_name:
        position = index

if position == -1:
    print("Pupil not found")
else:
    print("Class:", pupils[position].registration_class)
```
