# File Handling: CSV Files

!!! info "What you need to know"

    You must be able to describe, exemplify and implement opening, creating,
    reading, writing and closing sequential CSV files.

CSV means **comma-separated values**. Each line is a record and each comma
separates its fields.

```csv
Peter,17,R1
Laura,16,R1
Marie,16,R2
```

## Creating and Writing a CSV File

```python linenums="1"
import csv

file = open("pupils.csv", "w", newline="")
writer = csv.writer(file)
writer.writerow(["Peter", 17, "R1"])
writer.writerow(["Laura", 16, "R1"])
file.close()
```

`writerow()` writes one row. `newline=""` prevents blank rows appearing
between records on some systems.

## Reading Sequentially

```python linenums="1"
import csv

file = open("pupils.csv", "r", newline="")
reader = csv.reader(file)

for row in reader:
    name = row[0]
    age = int(row[1])
    registration_class = row[2]
    print(name, age, registration_class)

file.close()
```

CSV values are read as strings. Convert a value when another data type is
needed, as shown by `int(row[1])`.

## Connecting Rows to Records

Each row can be used to create a record:

```python linenums="1"
pupil = Pupil(row[0], int(row[1]), row[2])
pupils.append(pupil)
```
