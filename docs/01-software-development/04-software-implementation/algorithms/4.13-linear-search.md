# Linear Search

!!! info "What you need to know"

    You must be able to describe, exemplify and implement a linear search
    using a 1D array or an array of records.

A **linear search** checks each element in order until the whole array has been
searched. It can record whether a target exists or the position where it was
found.

## Recording Whether a Target Was Found

```python linenums="1"
names = ["Aisha", "Lewis", "Maya", "Callum"]
target = input("Enter a name: ")
found = False

for index in range(len(names)):
    if names[index] == target:
        found = True

print("Name found:", found)
```

The Boolean begins as `False` and only changes when an element matches the
target.

## Recording the Position

```python linenums="1"
position = -1

for index in range(len(names)):
    if names[index] == target:
        position = index
```

`-1` is used because it cannot be a valid array index. If it remains `-1`, the
target was not found.

!!! warning "Check before using the position"

    Do not use `array[position]` until you have checked that `position` is not
    `-1`.

## Search Checklist

1. Set `found` to `False` or `position` to `-1`.
2. Traverse the array.
3. Compare each element with the target.
4. Update `found` or `position` when a match occurs.
