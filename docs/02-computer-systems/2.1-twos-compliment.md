# Storing Negative Numbers (Two's Complement)

!!! info "What you need to Know"

    **Describe and exemplify the use of binary to represent positive and negative integers using two’s complement, including the range of numbers that can be represented using a fixed number of bits.**

## Sign bits

The first bit in a binary number is called the **sign bit**. It is the bit furthest to the left.

In two's complement:

* a sign bit of **0** means the number is positive
* a sign bit of **1** means the number is negative

The method for representing negative numbers is called **two's complement**.

## Creating a negative number

To store a negative number, computers use a method called **two's complement**.

To create a negative number using two's complement, use this method:

1. Write out the positive version of the number.
2. Flip all the bits.
3. Add 1.

This is often remembered as:

**Think positive → Flip the bits → Add 1**

!!! tip "Remember"

    To create a negative number:

    **Think Positive → Flip the Bits → Add 1**

!!! example "Example 1"

    Find the binary number for **-75**.

    First, write out **+75**.

    +75 = 64 + 8 + 2 + 1

    | Step | Binary |
    |------|--------|
    | Think positive | ==0100 1011== |
    | Flip the bits | ==1011 0100== |
    | Add 1 | ==1011 0101== |

    The ==Add 1== row is found by adding ==0000 0001== to the flipped bits:

    | Step | Binary |
    |------|--------|
    | Flipped bits | ==1011 0100== |
    | Add 1 | ==0000 0001== |
    | Result | ==1011 0101== |

    In this example, the flipped bits end in ==0==, so adding ==1== changes the last bit to ==1==. There is no carry.

    So **-75** is stored as:

    **1011 0101**

!!! example "Example 2"

    Find the binary number for **-28**.

    First, write out **+28**.

    +28 = 16 + 8 + 4

    | Step | Binary |
    |------|--------|
    | Think positive | ==0001 1100== |
    | Flip the bits | ==1110 0011== |
    | Add 1 | ==1110 0100== |

    The ==Add 1== row is found by adding ==0000 0001== to the flipped bits:

    | Step | Binary |
    |------|--------|
    | Flipped bits | ==1110 0011== |
    | Add 1 | ==0000 0001== |
    | Result | ==1110 0100== |

    In this example, the flipped bits end in ==11==. Adding ==1== changes those ending ==1==s to ==0==s until the first ==0== becomes ==1==.

    So **-28** is stored as:

    **1110 0100**

## Reading a Two's Complement Number

### Step 1: Look at the first bit

| First Bit | Meaning |
|------------|----------|
| 0 | Positive number |
| 1 | Negative number |

### If the first bit is 0

Convert the number to denary as normal.

Example:

**0100 1011**

64 + 8 + 2 + 1 = **75**

---

### If the first bit is 1

Use the following method:

1. Flip all the bits
2. Add 1
3. Convert to denary
4. Add a minus sign

!!! example "Example"

    Read **1110 0100**

    | Step | Result |
    |------|--------|
    | Original number | 1110 0100 |
    | Flip the bits | 0001 1011 |
    | Add 1 | 0001 1100 |
    | Convert to denary | 16 + 8 + 4 = 28 |
    | Add minus sign | **-28** |

    Therefore:

    **1110 0100 = -28**

!!! tip "Exam Tip"

    Always check the first bit before doing anything else.

    * **0 = Positive**
    * **1 = Negative**

## Range

### 8-bit Two's Complement Range

**-128 to 127**

You should know this range for Higher Computing Science.

### Why?

An 8-bit number has **256 possible combinations**.

Because two's complement stores both positive and negative numbers:

* Half are used for negative numbers.
* Half are used for positive numbers and zero.

| Smallest Value | Largest Value |
|---------------|--------------|
| -128 | 127 |

### Easy Way to Remember

For an **n-bit** two's complement number:

**Range = -2^(n-1) to (2^(n-1) - 1)**

For 8 bits:

* Smallest value = -2^7 = **-128**
* Largest value = 2^7 - 1 = **127**

!!! tip "Exam Tip"

    Many pupils incorrectly write:

    **-127 to 127**

    The correct range is:

    **-128 to 127**

    There is always **one more negative number than positive number**.
