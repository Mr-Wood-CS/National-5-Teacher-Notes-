# Pre-defined Functions

!!! info "What you need to know"

    You must be able to describe, exemplify and implement pre-defined functions
    with parameters to create substrings, convert characters to character codes
    and back, convert floating-point values to integers, and calculate modulus.

A pre-defined function is supplied by the programming language. It can be
called without writing its algorithm yourself.

## Substrings

A substring is part of a string. Python slicing uses a start index that is
included and an end index that is excluded.

```python linenums="1"
message = "Higher Computing"
course = message[0:6]
subject = message[7:16]
```

`course` becomes `"Higher"` and `subject` becomes `"Computing"`.

## Character Codes

Python's `ord()` converts one character to its Unicode code point; `chr()`
performs the reverse operation. For ordinary ASCII characters, these values
match their ASCII codes.

```python linenums="1"
code = ord("A")       # 65
character = chr(66)  # "B"
```

## Floating Point to Integer

`int()` converts a floating-point value to an integer by discarding the
fractional part (truncating towards zero). This is not rounding.

```python linenums="1"
positive = int(7.9)   # 7
negative = int(-7.9)  # -7
```

## Modulus

The modulus operator `%` returns the remainder after integer division.

```python linenums="1"
remainder = 17 % 5  # 2

if number % 2 == 0:
    print("Even")
```

Common uses include checking whether a number is even, wrapping a counter, and
testing divisibility.

## Summary

| Requirement | Python example |
|---|---|
| Create a substring | `word[start:end]` |
| Character to code | `ord(character)` |
| Code to character | `chr(code)` |
| Floating point to integer | `int(value)` |
| Modulus | `value % divisor` |
