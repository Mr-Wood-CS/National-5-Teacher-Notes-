# System Performance Tasks

Use [Factors Affecting System Performance](3.3-system-performance.md) to help you complete these activities.

## Task One: clock speed

1. Define processor clock speed.
2. State the unit used to measure it and write the unit's full name.
3. Explain why a higher clock speed can improve performance.
4. Explain why clock speed alone cannot prove that one processor is faster than another.

## Task Three: multi-core processors

1. Explain what a multi-core processor is.
2. State the number of cores in dual-, quad-, hexa- and octa-core processors.
3. Explain how multiple cores can improve performance.
4. Explain why a 3 GHz quad-core processor is not the same as a 12 GHz processor.
5. Explain why software design affects the benefit gained from extra cores.

## Task Four: data-bus width

1. Describe the purpose of the data bus.
2. Explain what is meant by a 32-bit data bus and a 64-bit data bus.
3. Explain how a wider data bus can improve performance.
4. Identify one other factor that affects how quickly data can be transferred.

## Task Five: cache

1. Explain why cache can improve system performance.
2. Describe what happens during a cache hit.
3. Describe what happens during a cache miss.
4. Compare L1, L2 and L3 cache.
5. Explain why increasing cache size does not remove the need for RAM.

## Task Six: evaluate a claim

A computer advert says:

> This computer must be twice as fast because it has twice as many processor cores.

Evaluate the claim. Refer to clock speed, processor design, software, cache and the type of task being performed.
