# Fetch–Execute Cycle Tasks

Use [The Fetch–Execute Cycle](3.2-fetch-execute-cycle.md) to help you complete these activities.

## Task One: order the cycle

Put these events into the correct order:

- The instruction is decoded by the control unit.
- The processor sends a read signal.
- The instruction is placed in the instruction register.
- The processor places the address of the next instruction on the address bus.
- The instruction travels from memory on the data bus.
- The instruction is executed.

## Task Two: trace an instruction

The first required instruction is stored at address ==1023==.

Draw a diagram containing:

- the control unit;
- the ALU;
- the program counter;
- the instruction register;
- RAM;
- the address, data and control buses.

Add numbered arrows to show one complete fetch–execute cycle and the fetch step that begins the next cycle.

## Task Three: explain the cycle

In your own words, write a paragraph that explains the fetch–execute cycle. Use all of these terms accurately:

**program counter**, **address bus**, **control bus**, **data bus**, **instruction register**, **decode**, **execute**.

## Task Four: apply your knowledge

Explain why each statement is incorrect.

1. The address bus carries the instruction from RAM to the processor.
2. The instruction register stores every instruction in the program.
3. The ALU fetches and decodes every instruction.
