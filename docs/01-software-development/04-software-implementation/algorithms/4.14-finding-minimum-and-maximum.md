# Finding Minimum and Maximum

!!! info "What you need to know"

    You must be able to describe, exemplify and implement algorithms that find
    the minimum and maximum using a 1D array or an array of records.

The algorithm keeps the best value found so far. It begins with the first
element, then compares every value with it.

## Finding the Maximum

```python linenums="1"
scores = [33, 12, 46, 18, 49, 27]
highest = scores[0]

for index in range(len(scores)):
    if scores[index] > highest:
        highest = scores[index]

print("Highest score:", highest)
```

Starting with `scores[0]` works even if every value is negative. Starting with
`0` would not.

## Finding the Minimum

```python linenums="1"
lowest = scores[0]

for index in range(len(scores)):
    if scores[index] < lowest:
        lowest = scores[index]

print("Lowest score:", lowest)
```

The only algorithmic difference is the comparison operator.

## Using an Array of Records

```python linenums="1"
highest = pupils[0].mark

for index in range(len(pupils)):
    if pupils[index].mark > highest:
        highest = pupils[index].mark
```
