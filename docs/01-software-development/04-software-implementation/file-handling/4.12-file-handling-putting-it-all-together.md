## Task: Competition Scores

A text file named `scores.txt` stores one score on each line:

```text
55
72
64
```

Write a modular program that:

1. opens `scores.txt` for reading
2. reads every score into an array of integers
3. closes the file
4. calculates the highest score
5. displays `Highest score: 72`

Use one sub-program to read the scores, one function to find the highest score
and one procedure to display it.

??? example "Extension Tasks"

    ### Extension 1: Write a Result

    Write the highest score to a new file named `result.txt`.

    ### Extension 2: Use CSV

    Change the input file so each row stores a player name and score. Display
    the name and score of the winning player.
