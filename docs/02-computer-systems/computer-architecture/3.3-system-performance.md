# Factors Affecting System Performance

!!! info "What you need to know"

    **Explain how processor clock speed, number of cores, data-bus width and cache affect system performance.**

System performance depends on how quickly the computer can process instructions and move required data. No single specification guarantees that one computer will be faster than another: processor design, software, memory, storage and workload all matter.

## Processor clock speed

The processor uses regular electrical pulses to coordinate its operations. **Clock speed** is the number of clock cycles completed each second and is measured in **hertz (Hz)**.

Modern processor speeds are commonly stated in **gigahertz (GHz)**:

**1 GHz = 1,000,000,000 clock cycles per second**

A higher clock speed means that a processor can complete more cycles per second. When comparing otherwise similar processors, this can improve performance. However, different processor designs may complete different amounts of work per cycle, so clock speed alone is not a reliable comparison between unrelated processors.

## Processor cores

A **multi-core processor** contains two or more processing cores in one package. Each core can execute its own sequence of instructions.

| Name | Number of cores |
| --- | ---: |
| Dual-core | 2 |
| Quad-core | 4 |
| Hexa-core | 6 |
| Octa-core | 8 |

Multiple cores allow suitable tasks to run in parallel. This can improve multitasking and speed up software designed to divide work between cores.

!!! warning "Core count is not a multiplier"

    A quad-core 3 GHz processor does **not** run one program at 12 GHz. Each core runs at its stated clock speed, and performance improves only when work can be divided efficiently.

## Data-bus width

The **width of the data bus** is the number of bits it can transfer at the same time.

- A 32-bit data bus can transfer 32 bits in one transfer.
- A 64-bit data bus can transfer 64 bits in one transfer.

With otherwise comparable systems, a wider data bus can move more data per transfer and reduce the number of transfers required. Actual performance also depends on bus speed, memory speed and whether the processor needs that amount of data.

!!! note "32-bit and 64-bit systems"

    The labels *32-bit* and *64-bit* can also describe a processor's registers, instruction set or memory-address size. They do not always refer only to the physical width of one bus.

## Cache memory

Cache is smaller and faster than RAM. It keeps copies of instructions and data that the processor is likely to use soon.

When the processor needs an item:

1. It checks the cache.
2. If the item is present, a **cache hit** occurs and it can be accessed quickly.
3. If the item is absent, a **cache miss** occurs. The item must be retrieved from a slower level of memory and a copy may be placed in the cache.

Cache works because programs often reuse the same data or access instructions and data stored close together.

### Cache levels

Processors commonly use several cache levels:

| Level | General characteristics |
| --- | --- |
| **L1** | Smallest and fastest; normally located within each core. |
| **L2** | Larger but usually slower than L1; may belong to one core or be shared. |
| **L3** | Larger again and usually shared by several cores; slower than L1 and L2 but faster than RAM. |

## Comparing systems fairly

Performance claims should be based on an appropriate test or **benchmark**, not a single specification. A fair comparison uses the same task, software settings and conditions on each system.
