# Creating and Calling Sub-programs

!!! info "What you need to know"

    You must be able to describe, exemplify and implement procedures,
    functions, parameter passing, and formal and actual parameters.

The **main program** controls the solution by calling sub-programs in the
required order.

## A Procedure Without Parameters

Start with a procedure that performs one action:

```python linenums="1"
def display_heading():
    print("Pupil Results")

display_heading()
```

`def` defines the procedure. The final line calls it. Program execution moves
into the procedure and returns to the main program when the procedure ends.

## Passing Data into a Procedure

Most sub-programs need data from the caller. A **parameter** allows that data
to be passed in.

```python linenums="1"
def display_result(name, score):
    print(name, "scored", score)

pupil_name = "Aisha"
pupil_score = 84
display_result(pupil_name, pupil_score)
```

The values flow from the main program into the procedure:

```text
display_result(pupil_name, pupil_score)
                    |             |
                    v             v
     def display_result(name, score):
```

## Formal and Actual Parameters

| Term | Example | Meaning |
|---|---|---|
| Formal parameter | `name`, `score` | Placeholder in the sub-program definition |
| Actual parameter (argument) | `pupil_name`, `pupil_score` | Value or variable supplied in the call |

The first actual parameter is passed to the first formal parameter, the second
to the second, and so on. Their order therefore matters.

## Returning Data from a Function

A function sends a result back with `return`:

```python linenums="1"
def calculate_percentage(mark, total):
    percentage = mark / total * 100
    return percentage

pupil_percentage = calculate_percentage(42, 50)
print("Percentage:", pupil_percentage)
```

`mark` and `total` are inputs. `percentage` is the output. The returned value is
stored in `pupil_percentage` in the main program.

## Procedure or Function?

| Feature | Procedure | Function |
|---|---|---|
| Performs a task | Yes | Yes |
| Can receive parameters | Yes | Yes |
| Returns a result to the caller | No | Yes |
| Typical call | `display_result(name, score)` | `result = calculate_total(price, quantity)` |

Use a function when another part of the program needs the calculated value.
Use a procedure when the sub-program only needs to perform an action.

## A Complete Modular Program

```python linenums="1"
def get_mark():
    mark = int(input("Enter the mark: "))
    return mark

def calculate_percentage(mark, total):
    percentage = mark / total * 100
    return percentage

def display_percentage(percentage):
    print("Percentage:", percentage)

pupil_mark = get_mark()
pupil_percentage = calculate_percentage(pupil_mark, 50)
display_percentage(pupil_percentage)
```

Read the final three lines first to see the overall flow. The sub-program
definitions contain the detail for each stage.

!!! tip "Exam language"

    Formal parameters appear in the **definition**. Actual parameters appear
    in the **call**. Inputs normally enter through parameters and outputs
    normally leave through `return`.
