# Software Implementation

!!! info "Higher course requirement"

    You must be able to **describe, exemplify, implement, read and explain** the
    structures, constructs and algorithms in this section using a procedural
    high-level language.

This section contains the implementation knowledge introduced or extended at
Higher. It assumes that you can already use National 5 constructs such as
variables, basic data types, selection, loops and ordinary 1D arrays.

## Suggested Learning Journey

Work through the lessons in this order. Each stage introduces ideas needed by
the lessons that follow.

1. **[Planning with sub-programs](04-software-implementation/4.1-subprograms/4.1-sub-programs.md)** — divide a problem into
   modules and identify their names, inputs and outputs.
2. **[Creating and calling sub-programs](04-software-implementation/4.1-subprograms/4.2-parameter-passing.md)** — implement
   procedures, functions, parameters and return values.
3. **[Scope of variables](04-software-implementation/4.1-subprograms/4.3-scope-of-variables.md)** — distinguish local and
   global variables and develop clear data flow.
4. **[Putting it all together](04-software-implementation/4.1-subprograms/4.4-sub-programs-putting-it-all-together.md)** — progress from
   reading small examples to implementing complete modular programs.
5. **[Pre-defined functions](04-software-implementation/4.2-pre-defined-functions/4.5-pre-defined-functions.md)** — use the required
   substring, character-code, integer-conversion and modulus operations.
6. **[Parallel 1D arrays](4.6-parallel-1d-arrays.md)** — connect related values
   using a shared index.
7. **[Records](04-software-implementation/records/4.7-records.md)** — combine fields of different data
   types.
8. **[Arrays of records](04-software-implementation/records/4.8-arrays-of-records.md)** — store and process
   several records.
9. **[Records: putting it all together](04-software-implementation/records/4.9-records-putting-it-all-together.md)**
   — apply records and arrays of records in one program.
10. **[Sequential text files](04-software-implementation/file-handling/4.10-file-handling-txt.md)** — create,
   read, write and close persistent text data.
11. **[Sequential CSV files](04-software-implementation/file-handling/4.11-file-handling-csv.md)** — process
    structured rows and fields.
12. **[File handling: putting it all together](04-software-implementation/file-handling/4.12-file-handling-putting-it-all-together.md)**
    — read, process and write file data in a modular program.
13. **[Linear search](04-software-implementation/algorithms/4.13-linear-search.md)** — locate a target in a
    1D array or array of records.
14. **[Find minimum and maximum](04-software-implementation/algorithms/4.14-finding-minimum-and-maximum.md)**
    — track an extreme value while traversing a collection.
15. **[Count occurrences](04-software-implementation/algorithms/4.15-count-occurrences.md)** — count values
    or records that satisfy a condition.
16. **[Algorithms: putting it all together](04-software-implementation/algorithms/4.16-algorithms-putting-it-all-together.md)**
    — combine the three standard algorithms in one problem.

The final Algorithms activity applies the structures, loops and indexing
developed in the earlier lessons.

## What Is Prerequisite Knowledge?

Input/output, assignment, arithmetic, string concatenation, Boolean logic,
selection, fixed and conditional loops, and basic 1D-array traversal remain
necessary programming knowledge. They are inherited from National 5 rather
than new Higher implementation outcomes, so they are used throughout these
pages instead of being repeated as separate Higher topics.
