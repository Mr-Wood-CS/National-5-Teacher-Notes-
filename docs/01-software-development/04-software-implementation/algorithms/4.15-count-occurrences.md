# Count Occurrences

!!! info "What you need to know"

    You must be able to describe, exemplify and implement a count-occurrences
    algorithm using a 1D array or an array of records.

A **count-occurrences** algorithm counts how many elements satisfy a condition.

## Counting Exact Matches

```python linenums="1"
cars = ["Ford", "Ford", "Toyota", "Kia", "Ford"]
target = input("Enter a make: ")
count = 0

for index in range(len(cars)):
    if cars[index] == target:
        count = count + 1

print("Matching cars:", count)
```

## Counting Values That Meet a Condition

```python linenums="1"
marks = [72, 41, 88, 50, 36, 61]
pass_count = 0

for index in range(len(marks)):
    if marks[index] >= 50:
        pass_count = pass_count + 1

print("Passes:", pass_count)
```

!!! warning "Count or total?"

    A count adds `1` for each match. A running total adds the value itself.

## Count Checklist

1. Set the count to `0`.
2. Traverse the array.
3. Test each element against the condition.
4. Add `1` when the condition is true.
