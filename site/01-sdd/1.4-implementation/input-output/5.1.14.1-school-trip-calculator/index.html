    Task 1: School Trip Calculator

    You are going to make a small program for a school trip.

    It will work out the total cost and the cost for each pupil.

    What the Program Should Do

    Ask for:

    • the pupil's name
    • the destination
    • the number of pupils
    • the entry cost per pupil
    • the bus cost

    Then calculate:

    • the total entry cost
    • the total trip cost
    • the cost per pupil

    Decide how each item should be stored. Short answers are fine.

    Data Item Data Type Data Structure Reason
    Pupil name
    Destination
    Number of pupils
    Entry cost per pupil
    Total bus cost
    Cost labels

    Task 3: Design

    Plan your program before you code it.

    Use draw.io if you are creating a structure diagram or flowchart.

    Take a screenshot of your finished diagram and add it to your worksheet.

    Choose one:

    • pseudocode
    • a structure diagram
    • a flowchart

    Show this order:

    1. get the information
    2. calculate the costs
    3. display the summary

    Task 4: Code

    Create the program in Python.

    Take a screenshot of your finished code and add it to your worksheet.

    Use this array:

    costLabels = ["Entry total", "Bus cost", "Total cost"]

    This array stores three pieces of text under one name.

    Each item in the array is a label you can use when displaying the results:

    • costLabels[0] is "Entry total"
    • costLabels[1] is "Bus cost"
    • costLabels[2] is "Total cost"

    Using an array here keeps the related labels together instead of making three separate variables.

    Remember:

    • use int() for whole numbers
    • use float() for money
    • add comments to explain the main parts
