## Task: Athletics Results

An array stores the times, in seconds, for six runners:

```python
times = [12.4, 11.8, 13.1, 11.8, 12.0, 14.2]
```

Write a modular program that:

1. finds and displays the fastest time
2. counts and displays how many runners achieved the fastest time
3. asks for a target time and uses a linear search to report whether it appears
   in the array

Test the search with:

| Target | Expected result |
|---:|---|
| 12.0 | Found |
| 10.5 | Not found |

The fastest time should be `11.8`, and its count should be `2`.
