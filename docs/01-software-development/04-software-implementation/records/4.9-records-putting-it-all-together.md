# Records: Putting It All Together

Create and test your solution in Python. Take a screenshot showing your code
and its output, then paste it into your workbook.

## Task: Library Books

A library wants to store details about three books.

Create a `Book` record with these fields:

| Field | Data type |
|---|---|
| `title` | String |
| `author` | String |
| `available` | Boolean |

Your program must:

1. create an array containing three `Book` records
2. input the field values for each book
3. display the title and author of every available book
4. keep the solution modular by using sub-programs for input and output

Test your program with:

| Title | Author | Available |
|---|---|---|
| Noughts and Crosses | Malorie Blackman | True |
| The Hobbit | J. R. R. Tolkien | False |
| Frankenstein | Mary Shelley | True |

The output should include `Noughts and Crosses` and `Frankenstein`, but not
`The Hobbit`.
